\# 🛡️ Cyber Fraud Detection Monitoring System



An AI-powered Cyber Fraud Detection and Monitoring System developed using Machine Learning, Streamlit, SHAP Explainable AI, SQLite, and interactive cybersecurity dashboards.



This project is designed to detect suspicious financial transactions, analyze fraud risk levels, provide AI explainability insights, and generate professional fraud monitoring reports.



\---



\# 🚀 Features



\## 🔍 AI Fraud Detection

\- Detects fraudulent and suspicious transactions using Machine Learning.

\- Predicts fraud probability and risk score.



\## 🧠 SHAP AI Explainability

\- Explains why the model predicted a transaction as fraud.

\- Visualizes feature impact analysis.



\## 📊 Interactive Monitoring Dashboard

\- Fraud analytics visualization

\- Risk score trends

\- Fraud vs Safe transaction distribution

\- High-risk transaction monitoring



\## 📂 CSV Bulk Fraud Analysis

\- Upload CSV files containing multiple transactions

\- Perform batch fraud prediction

\- Download analyzed results



\## 🗄️ SQLite Database Integration

\- Stores all transaction prediction history

\- Maintains monitoring logs



\## 📄 PDF Report Generation

\- Generate downloadable fraud monitoring reports

\- Includes fraud statistics and transaction summaries



\## 🔐 Authentication System

\- Admin login-based secure access



\## 🎨 Professional Cybersecurity UI

\- Dark-themed responsive UI

\- Modern cyber security dashboard styling

\# ⚙️ Installation



\## Clone Repository



```bash

git clone https://github.com/your-username/Cyber-Fraud-Detection-System.git

```



\## Navigate Into Project



```bash

cd Cyber-Fraud-Detection-System

```



\## Create Virtual Environment



```bash

python -m venv venv

```



\## Activate Virtual Environment



\### Windows



```bash

venv\\Scripts\\activate

```



\### Linux / Mac



```bash

source venv/bin/activate

```



\## Install Dependencies



```bash

pip install -r requirements.txt

```



\---



\# ▶️ Run Project



```bash

streamlit run app.py

```
